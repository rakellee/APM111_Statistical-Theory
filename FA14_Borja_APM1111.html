Mixed-Design ANOVA Analysis

by Borja, Rachelle Erika

Introduction

This study examined whether dating preferences were influenced by:

  • Gender (Male vs Female)
  • Looks (Attractive, Average, Ugly)
  • Personality (High Charisma, Some Charisma, No Charisma)

A mixed-design ANOVA was conducted to determine whether there was a three-way interaction among gender, looks, and personality on dating ratings.

Convert Data to Long Format

long_data <- data %>%
  
  mutate(
    
    Subject = factor(1:n()),
    
    Gender = as.factor(Gender)
    
  ) %>%
  
  pivot_longer(
    
    cols = att_high:ug_none,
    
    names_to = "Condition",
    
    values_to = "Rating"
    
  )

Create Looks and Personality Variables

long_data <- long_data %>%
  
  mutate(
    
    Looks = case_when(
      str_detect(Condition, "att") ~ "Attractive",
      str_detect(Condition, "av") ~ "Average",
      str_detect(Condition, "ug") ~ "Ugly"
    ),
    
    Personality = case_when(
      str_detect(Condition, "high") ~ "High Charisma",
      str_detect(Condition, "some") ~ "Some Charisma",
      str_detect(Condition, "none") ~ "No Charisma"
    )
    
  )

long_data$Looks <- factor(
  long_data$Looks,
  levels = c("Attractive", "Average", "Ugly")
)

long_data$Personality <- factor(
  long_data$Personality,
  levels = c(
    "High Charisma",
    "Some Charisma",
    "No Charisma"
  )
)

long_data <- na.omit(long_data)

Mixed-Design ANOVA

anova_results <- aov_car(
  
  Rating ~ Gender * Looks * Personality +
    
    Error(Subject/(Looks * Personality)),
  
  data = long_data,
  
  factorize = FALSE
  
)

Interpretation of Results

Three-Way Interaction

The mixed-design ANOVA revealed a significant three-way interaction between gender, looks, and personality.

This indicates that the combined effects of attractiveness and charisma on dating ratings differed between males and females.

Specifically:

  • Personality influenced dating ratings differently across attractiveness conditions.
  • High charisma generally increased dating ratings.
  • Personality appeared to compensate for lower physical attractiveness.
  • The strength of these effects differed between genders.

Significant Two-Way Interactions

Gender × Looks

This interaction suggests that males and females evaluated physical attractiveness differently.

Gender × Personality

This interaction indicates that charisma affected dating ratings differently depending on gender.

Looks × Personality

This interaction suggests that personality influenced dating ratings differently across attractiveness levels.

Main Effects

Gender

The main effect of gender examines whether males and females differed overall in dating ratings.

Looks

The main effect of looks examines whether attractiveness influenced dating ratings overall.

Personality

The main effect of personality examines whether charisma influenced dating ratings overall.

Overall Conclusion

The mixed-design ANOVA demonstrated that dating preferences were influenced by a combination of gender, physical attractiveness, and personality.

Overall, the personality had a strong influence on dating ratings.High charisma substantially improved dating evaluations. Personality compensated for lower physical attractiveness. The influence of attractiveness and personality differed between males and females.
